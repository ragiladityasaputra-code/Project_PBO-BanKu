# BanKu

Aplikasi Bank Sampah Digital berbasis Java (PBO), dijalankan lewat terminal.

- Tugas 4 Pemrograman Berorientasi Objek
- Project: Maven (NetBeans)
- Class utama: `com.mycompany.banku.App`

## Akun bawaan
- Petugas: `admin` / `admin123`
- Kode registrasi petugas baru: `BANKU2026`

## Cara menjalankan
Buka project di NetBeans lalu klik Run, atau lewat terminal:

    mvn compile exec:java
